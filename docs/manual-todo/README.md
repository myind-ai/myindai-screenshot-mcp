# Manual TODO tracker

This folder catalogues every action that needs a human in the loop — actions an agent can't take on its own. Items move to `done/` once completed.

| File | Owner | Status |
|---|---|---|
| `launch.md` | Shantanu | open |

## Rule

When the agent finds an item that needs human action, it appends to the appropriate file here with:

- Checkbox `- [ ]`
- WHAT exactly needs to happen
- WHERE to do it (URL, dashboard path)
- WHY it's needed (which sprint / feature unblocks)
- WHEN it must be done (blocker / launch-day / nice-to-have)
