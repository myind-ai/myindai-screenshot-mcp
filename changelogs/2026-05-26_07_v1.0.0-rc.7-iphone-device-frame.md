# v1.0.0-rc.7 — hand-drawn iPhone device frame

**Date:** 2026-05-26
**Type:** Feature (renderer)

## Summary

`mcp/frontend/three-renderer.js` is no longer a placeholder. It now draws a proper iPhone-shaped device chassis in pure Canvas 2D — original work, no upstream asset copying, no 3D model dependency. Renders look like an actual iPhone instead of a generic dark rectangle.

## What's new

- **Rounded iPhone chassis** with ~11% corner radius (matches modern iPhone Pro models).
- **Chrome rim** — a subtle 0.35 % stroke just inside the chassis edge that suggests a titanium / aluminium frame in light.
- **Inner bezel** — a darker ring between the chassis and the screen area, adding depth.
- **Opt-in dynamic island** — drawn ON TOP of the screenshot via `screenshot.dynamicIsland: true`. **Off by default** because iOS Simulator captures and real-device screenshots already include the native island; drawing ours on top would create a "stacked pill" artifact. Use the flag for Android source captures or stripped inputs that need an island added.
- **Device style switch** — `screenshot.deviceStyle: "iphone" | "rounded-rect"` selects the chassis treatment. Default is `"iphone"`.

## Surface (renderer contract)

```ts
three.drawDeviceFrame(ctx, frame)        // chassis — call BEFORE compositing the screenshot
three.drawDeviceForeground(ctx, frame)   // dynamic island — call AFTER the screenshot
```

`frame.dynamicIsland: boolean` controls the foreground island. Position / size constants are derived from real iPhone 15 Pro Max dimensions (125 × 37 px on a 1290 × 2796 screen → 10.5 % × 1.85 % of device width / height; 2 % top inset).

## Why pure Canvas 2D and not a .glb?

- No licensing concerns — every shape is geometric / hand-rolled.
- No `.glb` runtime download — the renderer stays asset-free, package size stays small.
- WebGL / real 3D path is reserved for v1.1.0 when we can ship licensed `.glb` device models (see `ASSETS.md`).

## Files Modified

- `mcp/frontend/three-renderer.js` — full rewrite. `drawDeviceFrame()` and `drawDeviceForeground()` now produce a real iPhone shape; `setupThreeRenderer()` returns `isPlaceholder: false`.
- `mcp/frontend/app.js` — `drawDeviceForeground()` helper added; `computeLayout()` now sets `device.dynamicIsland` from `screenshot.dynamicIsland`; the render pipeline calls the foreground after the screenshot composites.
- `mcp/src/server.ts` — version `1.0.0-rc.6` → `1.0.0-rc.7`.
- `mcp/package.json` — version `1.0.0-rc.6` → `1.0.0-rc.7`.
