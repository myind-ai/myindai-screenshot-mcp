# v1.0.0-rc.2 — strip legacy identity references, harden npm tarball

**Date:** 2026-05-26
**Type:** Refactor / Cleanup

## Summary

Final brand-cleanup pass before v1.0.0 stable. Removes every functional reference to the legacy development name from the shipped npm package. Provenance documentation in `docs/clean-room-rewrite.md` keeps the upstream-rewrite story intact (legal defence is unaffected); only product-identity strings move.

## Changes

- **MCP resource URI scheme** renamed from `appscreen://*` → `myindai://*` across `src/resources.ts`, `src/prompts.ts`, `src/server.ts`, smoke scripts, and design-guide prose. Every public resource (`myindai://presets`, `myindai://schema`, `myindai://design-guide`, `myindai://assets`, `myindai://memory`) now matches the package brand.
- **Runtime output directory** renamed `appscreen-output/` → `mcp-output/` across `src/tools/video-template.ts`, `scripts/render-showcase.ts`, `scripts/video.ts`. Existing local output folders are not migrated automatically; users can rename or delete safely.
- **Migration section dropped** from `mcp/README.md`. The published README no longer references the previous package name.
- **CLI prompt verbiage** in `src/prompts.ts` no longer mentions the old development name.
- **Top-level README** "Why a clean-room rewrite?" paragraph reduced to a tight "Provenance" pointer that links into `docs/clean-room-rewrite.md` rather than rehashing the upstream-rewrite narrative on the landing page.
- **CONTRIBUTING.md** clean-room policy generalised — the disqualified-source list lives canonically in `docs/clean-room-rewrite.md` rather than being duplicated in two places.
- **`mcp/NOTICE`** now exists at the package root so it actually ships in the npm tarball (was previously listed in `package.json#files` but only present at repo root, so it was silently absent from published versions).

## Migration impact

- **MCP clients** that have stored URI references (rare) to `appscreen://*` resources should re-fetch the resource list via `resources/list` and update bookmarks to `myindai://*` equivalents. There is no behavioural change other than the URI prefix.
- **Users who set `APPSCREEN_MEMORY_DIR` / `APPSCREEN_TELEMETRY_DIR`** must rename them to `MCP_MEMORY_DIR` / `MCP_TELEMETRY_DIR`. The rc.1 env-var aliases are not preserved (no public users yet — assessed as zero-cost rename).
- **Anyone holding the rc.1 install** can upgrade with `npx -y myindai-screenshot-mcp@latest` once published; the new `latest` tag points to rc.2.
