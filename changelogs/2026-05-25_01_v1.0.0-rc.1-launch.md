# v1.0.0-rc.1 — initial public release (clean-room preview)

**Date:** 2026-05-25
**Type:** Infrastructure / Feature

## Summary

Initial release of `myindai-screenshot-mcp` as a clean-room open-source project under MIT. The MCP server (25 tools, all original work) carries forward from the private v0.5.1 development line. The headless renderer (`mcp/frontend/`) is a from-scratch reimplementation against the contract documented in `docs/clean-room-rewrite.md` — zero lines of code derived from any other open-source or proprietary renderer.

Smoke test green on first run: 93ms for one `render_screenshot` call producing a valid 560 KB PNG at 1290×2796.

## Scope shipped

- Top-level project docs: README, LICENSE (MIT), CONTRIBUTING, CODE_OF_CONDUCT, NOTICE, ASSETS.
- Server-renderer architecture doc and clean-room-rewrite behavioural spec.
- Manual TODO tracker under `docs/manual-todo/`.
- MCP server (`mcp/`) renamed from `appscreen-mcp` → `myindai-screenshot-mcp`, version 1.0.0-rc.1, author updated.
- `mcp/scripts/prepack.mjs` rewritten as a validator (renderer files now live canonically at `mcp/frontend/`; no longer copied from repo root).
- New renderer files (clean-room): `mcp/frontend/{index.html, app.js, three-renderer.js, language-utils.js, styles.css}`. Total footprint 16.4 KB.
- New smoke harness `mcp/scripts/rc1-smoke.ts` that exercises the renderer contract without invoking the AI layer.
- Sample fixture committed under `assets/_provenance/sample-input.png` (the author's own Kaabil app screenshot).

## Working tool surface (v1.0.0-rc.1)

- `render_screenshot` — 1 template (`clean-minimal`), 3 declared device dimensions (iphone-15-pro-max, iphone-6.7, google-pixel-8).
- `list_presets`, `list_assets`, `list_video_templates` — catalogue tools.
- `--doctor` — environment health check.
- `record_telemetry`, `list_telemetry`, `memory_read`, `memory_write` — passive surfaces.
