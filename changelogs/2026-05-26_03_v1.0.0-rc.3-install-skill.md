# v1.0.0-rc.3 — bundled skill + `--install-skill` CLI

**Date:** 2026-05-26
**Type:** Feature (developer experience)

## Summary

The Claude Code skill now ships inside the npm tarball and is installable with one command:

```bash
npx -y myindai-screenshot-mcp --install-skill
```

That single line replaces the previous `curl … | sh` script flow. The user no longer has to clone the GitHub repo to get the skill.

## Changes

- **`src/server.ts`**: new `installSkill()` function + `--install-skill` / `install-skill` CLI handler. Probes two candidate skill paths (dev layout `pkg/../skills` and published layout `pkg/skills`) and copies the canonical `myindai-screenshot` skill folder into `~/.claude/skills/myindai-screenshot/`. Prints next-step instructions for wiring the MCP server too. Version bumped from `1.0.0-rc.2` → `1.0.0-rc.3` across all string occurrences.
- **`scripts/prepack.mjs`**: now also copies the top-level `skills/` folder into `mcp/skills/` so the published tarball contains the skill. Validates `mcp/skills/myindai-screenshot/SKILL.md` is present after copy; aborts the publish if missing. Tarball-presence note logged.
- **`package.json`**: `files` now includes `"skills"`. Version bumped to `1.0.0-rc.3`.
- **`--help` output**: documents `--install-skill` alongside `--doctor` / `--version` / `--help`.

## Manual install path (still supported)

The original `git clone … && cp -r skills/ ~/.claude/skills/` and `curl … | sh` flows still work for users without Node — see `skills/README.md` and `skills/install.sh`.
