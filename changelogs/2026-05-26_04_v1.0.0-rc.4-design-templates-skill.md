# v1.0.0-rc.4 — ship battle-tested design skill alongside install skill

**Date:** 2026-05-26
**Type:** Feature (developer experience)

## Summary

The npm package now ships **two** Claude Code skills, both copied to `~/.claude/skills/` by a single `npx -y myindai-screenshot-mcp --install-skill` command:

1. `myindai-screenshot` — install + setup + basic workflow (existing).
2. `myindai-screenshot-templates` — **new**. Battle-tested design recipes: 10 named template archetypes (5 2D + 5 3D), canvas math that prevents text-device overlap and wasted negative space, panoramic split for paired adjacent screenshots, source-frame selection rules, and a renderer-feature support matrix (which template lands in which rc).

## Changes

- **`skills/myindai-screenshot-templates/SKILL.md`** — new, 220+ lines, adapted from a battle-tested skill that solved 60+ wasted renders on the Kaabil launch. Documents:
  - The locked-in canvas math (`scale: 73, x: 50, y: 80` + `text.offsetY: 8`)
  - 5 2D archetypes: Pink Vibrant, Dark Premium, Bold Big-Number, Tilt Synthwave, Clean Minimal
  - 5 3D archetypes: Glass Aurora, Neon Perspective, Ocean Hero, Gold Premium, Light Cinematic
  - Panoramic split technique (`screenshot.x: 130` + `x: -30` paired) for two-screenshot continuity
  - Headline + subheadline sizing rules
  - Workflow (6 frames × N templates in parallel batches, ASC upload)
  - Source-frame selection (show app working, not empty states)
  - Output naming convention (`1_<feature>.png` … `6_<feature>.png`)
  - "When to use which template" decision table
  - 8-row gotchas table
  - **Renderer-support matrix** mapping each template to the rc it lands in (so users on rc.4 know what works today vs what activates as the renderer catches up — no skill rewrite needed)
- **`mcp/src/server.ts`** — `installSkill()` now walks every subdirectory under `skills/`, copies each one that contains a `SKILL.md` into `~/.claude/skills/`. Prints one ✅ line per installed skill. Version bumped to `1.0.0-rc.4`.
- **`mcp/scripts/prepack.mjs`** — validator now asserts that at least one subfolder under `skills/` has a `SKILL.md` and logs the names of every shipped skill on pack.
- **`skills/install.sh`** — `curl | sh` path also loops over every `skills/<name>/` with a `SKILL.md` instead of hardcoding `myindai-screenshot`.
- **`skills/README.md`** — both skills listed in the index; install instructions now lead with `npx -y myindai-screenshot-mcp --install-skill` (manual `git clone` and `curl | sh` paths preserved as alternates).

## Status snapshot

Renderer-feature support is unchanged in rc.4 — only the templates skill is new. The matrix in the new skill is the source of truth for "what works today vs what's coming." Recipe 05 (Clean Minimal) renders end-to-end in rc.3+; the other 9 recipes have a documented degraded path you can use now, and the full version activates as renderer features ship across rc.4 → rc.3.x.
